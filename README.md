# 말끔이 — 내 컴퓨터 청소 매니저

출품작 (2026-11). "크고 복잡한 것 말고, 작지만 정교한 것."

## 뭐가 다른가

1. **앱별 캐시 등록부** — 캐시를 쌓는 프로그램을 하나씩 등록해 임계치로 관리. 🔍 자동 서치가
   AppData를 뒤져 캐시 쓰는 앱을 찾아 후보로 제안하고, 사용자가 승인한 것만 등록된다.
2. **절대 바로 지우지 않는다** — 스캔 → 미리보기(목록·용량) → 승인 → 휴지통 경유. 사용 중 파일은 건너뜀.
3. **광고 점검·차단** — 광고 유입 4경로(자동실행·작업 스케줄러·브라우저 확장·알림 허용)를 읽기 전용
   스캔 + hosts 기반 시스템 전체 광고 차단(StevenBlack 목록, 자동 백업·원클릭 해제).
4. **"이런 것들이 사용되지 않고 있어요!"** — 라이브러리 파일이 아니라 사람이 아는 덩어리(앱·폴더·파일)
   단위로 오래 안 쓴 것을 찾아 알림. 삭제가 아니라 「말끔이 보관함」으로 분리 + 되돌리기.
5. **일반인용 상태 화면** — 숫자 대신 "지금 컴퓨터가 왜 느린지" 문장 + 게이지.
6. **상주 없음** — 주기 청소는 윈도우 작업 스케줄러 등록으로(매일, 임계치 초과분만).
7. **시작프로그램 끄기** — 삭제가 아니라 작업관리자와 같은 StartupApproved 방식의 가역 비활성화.
8. **중복 파일 찾기** — 크기→부분해시→전체해시(SHA-256) 3단 필터, 사본은 보관함으로 분리.
9. **디스크 지도** — 폴더 클릭으로 파고드는 한 계층씩 측정(기다림 없음, 정션 제외).

## 실행

```
py -3.12 -m pip install -r requirements.txt
py -3.12 app.py            # 창 모드 (hosts 차단·Prefetch 는 관리자 권한으로 실행해야 동작)
py -3.12 app.py --selftest # 창 없이 코어 점검
```

## 구조

```
app.py            pywebview 창 + JS 브리지 (--auto-clean: 스케줄러용 자동 청소)
core/sysinfo.py   상태 대시보드 (psutil, 읽기 전용)
core/cache_registry.py  앱별 캐시 등록부 + 자동 서치(discover)
core/cleaner.py   미리보기 → 승인 → 휴지통 경유 삭제
core/adscan.py    광고 유입 4경로 스캔 (읽기 전용)
core/adblock.py   hosts 차단 적용/해제 (백업·마커 구간·DNS 플러시)
core/unused.py    안 쓰는 덩어리 탐지·분리·되돌리기 (+ Prefetch 프로그램 기록)
core/scheduler.py 작업 스케줄러 등록/해제
ui/               화면 (기능 단계 — 디자인 패스는 별도)
```
